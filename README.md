# Portfolio de Francisco José Romero Anguita

## Actualizar la web existente

1. Sube `index.html` y `styles.css` a la raíz del repositorio para reemplazar las versiones anteriores.
2. Arrastra también la carpeta `certificados` completa en la misma pantalla de subida. Debe quedar en la raíz, junto a `index.html`.
3. Pulsa **Commit changes**. GitHub Pages actualizará la web con la configuración ya existente.

No subas el ZIP ni una carpeta contenedora llamada portfolio. Los certificados deben conservar las rutas y nombres incluidos.

## Contenido

Cinco documentos: cuatro certificados de finalización de Hack4u y un certificado de asistencia de BIG school. Las certificaciones de pentesting en preparación se mantienen separadas.

La web usa enlaces relativos y funciona en https://roma-software.github.io/ y en rutas de proyecto. No necesita compilación.
